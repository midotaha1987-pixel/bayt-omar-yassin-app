# بيت عمر وياسين ومعاهم نونو — نسخة أندرويد

لعبة أطفال تعليمية بالعربية (RTL، لهجة مصرية) لسن ٦ سنين ونص (أولى ابتدائي):
عمر وياسين توأم أبطال، ومعاهم نونو كمرشد. أوضة المعيشة، المطبخ، أوضة اللعب،
محطة ألغاز نونو (عدّ، ذاكرة، كمّل الشكل)، دكان نونو بالنجوم، ولعبة قرآن
(حفظ آية بالتكرار — سورة الفيل، تلاوة العفاسي).

- **بدون إعلانات، بدون تسجيل دخول، بدون مشتريات، بدون روابط خارجية.**
- **تعمل كاملة بدون إنترنت** — كل الصوت (راوي مسجّل + تلاوة) مدمج في التطبيق.
- التقدّم والنجوم محفوظان على الجهاز فقط (localStorage).
- سياسة خصوصية الأطفال: [privacy.html](privacy.html) — منشورة على GitHub Pages.

## نسخة الأندرويد (APK)

التثبيت المباشر (debug):
https://github.com/midotaha1987-pixel/bayt-omar-yassin-app/releases/download/apk-v1.0.0/bayt-omar-yassin-v1.0.0.apk

- الحزمة: `com.bayt.omar.yassin` — الإصدار 1.0.0 (versionCode 1)
- البناء: GitHub Actions (`.github/workflows/build-android-apk.yml`) — Node 22 + JDK 21
- التوقيع: debug keystore ثابت ملتزم في `android/app/bayt-omar-yassin-debug.keystore`
  (كلمة المرور التقليدية `android`) — لا تغيّره أبداً، وإلا رفض أندرويد تثبيت
  النسخ الجديدة فوق القديمة. نسخة Google Play المستقبلية ستستخدم مفتاح
  إصدار منفصلاً يُدار عبر أسرار GitHub.

## تطوير

- اللعبة نفسها (`index.html` + `assets/`) منسوخة حرفياً من الأرتيفكت `lm-l-lgz`
  — لا تعدّلها هنا؛ التعديلات تأتي من الأرتيفكت.
- `npm run sync` ينسخ ملفات الويب إلى `www/` ثم `npx cap sync android`.
- سياسة الخصوصية تُنشر على GitHub Pages من فرع `main` (إعداد Pages في المستودع).
